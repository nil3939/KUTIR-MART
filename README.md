# 🛍️ Kutir Mart

### Heritage & Lifestyle E-Commerce Platform

**Kutir Mart** is a modern e-commerce and department-store web application designed to provide a seamless online shopping experience for customers looking for **artisan products, lifestyle essentials, electronics, books, furniture, fashion, travel accessories, and more**.

🌐 **Live Website:** https://kutirmart.netlify.app/

---

## 📌 Overview

Kutir Mart combines a modern shopping interface with essential e-commerce functionality to create a complete online retail experience.

The platform allows users to:

* 🛒 Browse products and categories
* 🔎 Explore different product collections
* ❤️ Manage their wishlist
* 🛍️ Add products to cart
* 💳 Complete checkout
* 📦 Track orders
* 👤 Manage their customer account
* 💰 Select different payment methods
* 🎟️ Apply promotional/coupon codes
* 🚚 Follow delivery status
* 🔐 Access secure account features

The project is designed with a strong focus on **UI/UX, responsive design, usability, and a realistic e-commerce workflow**.
